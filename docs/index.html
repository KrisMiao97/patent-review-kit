对照预期意见 EX-01

What happens at exactly 40 lx?

This review note comes from a fictional pre-filing draft for a seedling box.

Draft [0018]
“The supplemental lamp turns on when illuminance is below 40 lx. The lamp turns off when illuminance is above 40 lx.” (English translation)
Evidence gap
Paragraph [0018] leaves out the lamp state at exactly 40 lx and the default state between power-up and the first valid reading. Figure 1 shows the signal path from the sensor through the controller to the lamp. The control logic still needs confirmation from engineering.
Conditional edits

Confirm the behavior with engineering before choosing one of these edits to [0018]. Both examples assume the lamp stays off from power-up until the first valid reading.

If the lamp retains its state at 40 lx, add the confirmed power-up rule and “At exactly 40 lx, the lamp retains its previous state.”

If the lamp switches off at 40 lx, change the shutoff condition to “The lamp turns off when illuminance is at least 40 lx” and add the confirmed power-up rule.
