换成自己的图解时，怎样补查公开说明书？

本例可直接查看。另做图解时，如果已有公开号，但手头资料和已授权来源仍无法定位对应实施例，可补充同件公报。确需申请智慧芽 MCP 权限时可填写积分申请表。已有权限可按教程配置服务地址和 MCP Key，再检查可用工具。实物尺寸、外形或配合间隙仍需产品资料核实。
