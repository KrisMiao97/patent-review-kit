# 附图、工况和权项分支

在本轮范围内，附图可读时实际逐图查看。有控制条件、故障工况或替代结构时，按下文展开受影响的技术关系。报告分别记录已经核查的内容、证据缺口和问题处理状态。

扫描 PDF 没有可提取文本，不代表附图不能核读；先实际渲染并查看。原图可读时，在离线报告内保留带页码的图像证据。压缩前后检查标号、引出线和比例，测量最终文件体积再决定是否调整。附图缩略图不能替代逐图核读记录，也不能据静态图推定性能、控制时序或测距精度。

## 附图怎样核查

1. **先核版本和页图。** 从说明书的附图说明、正文引用和随稿图纸列出预期图号。打开 PDF 对应页图、Word 渲染页或原始图像逐图查看，记录稿件版本、实际核读的文件页码与图号。同页有多图时分别记录。只有 OCR、文字提取或图题时，附图状态仍为「附图未核读」。图纸与正文版本不明时，保留版本疑点，等待同版材料。
2. **逐图检查引用和标记。** 核对附图说明、正文引用、图号、标号、名称与引出线是否对应。检查缺图、同一标号指向不同部件、同一部件跨视图称谓不一，以及引出线、剖切位置或运动箭头是否妨碍识读。引用到缺失的视图时，列出所需图号和对应段落。
3. **逐项核对技术关系。** 每项独立权利要求按技术特征拆行，有疑点的从属项按引用路径拆行。定位到权项原句、说明书段落、图号和文件页码。写清图上能看到哪个部件装在哪里、与谁连接或配合，以及视图处于什么位置或工况。图区分不开的材料、尺寸、比例、内部连通、电气隔离、触发条件和性能效果，回到正文、交底或试验资料核查。图文冲突时保留双方位置，先确认哪份材料对应本轮方案。

| 图证状态 | 何时使用 |
| --- | --- |
| 图示可见 | 已实际看图，能够直接定位到所述对象或关系。写明图号、页码、标号和可见内容。 |
| 仅正文有记载 | 正文有明确依据，已查看相关附图，所核内容由正文交代且相关图未呈现。保留正文位置。 |
| 已看图但无法确认 | 已看相关图，但分辨率、遮挡、视角或图中信息不足。写清待核关系和需要的材料。 |
| 附图未核读 | 附图已取得但本轮未目视核对。注明未看图的原因和待核图号或页码。 |
| 附图缺失 | 预期附图未取得。写明缺图及其影响的权项或段落。 |
| 不适用 | 本行事项与附图无关。 |

同一图对不同特征可以有不同状态。连接关系、控制动作和性能各按对应证据判断，矩阵另写整行的综合核查结果。关键结论依赖模糊图时，给出需要补交的清晰原图、局部放大、剖视或状态图及其应呈现的关系。

## 尺寸比较和覆盖关系

1. **先定位并拆开核查。** 分别列出被比较的对象、尺寸名称、测量方向、参考轴或平面、量取位置和必要的工况。定位权项分句、说明书对应段落及图号。曲面上的沿面量取、截面量取和投影长度应分别核对。
2. **记录各项证据能确认什么。** 明确哪些条件在文字中写出，哪些可从标注的图中辨认，哪些需要原始工程图、样机或研发说明。图区分不开的尺寸标为待核。比照截图像素得出的数值，须核实图的比例、视角和基准后才能用于判断。
3. **把尺寸大小和覆盖分开。** 判断投影是否覆盖时，另核投影方向、参考面、两对象的相对位置、边缘对齐和局部开口。同方向上，若带宽 20 mm 并占据 10–30 mm 的位置，极片宽 12 mm 并占据 0–12 mm 的位置，带只覆盖两者重叠的 10–12 mm 区间。
4. **把术语澄清和新增限定分开。** 已确认实际测量方向且有相应原始依据时，可在比较语句中明确方向和基准，并同步附图尺寸和复述位置。若建议另增覆盖关系，说明它是否会改变保护范围，记录原始依据和适用阶段。实际方向尚待确认时，候选改法附采纳条件。

## 哪些条件需要展开工况表

原文出现数值阈值、角度、区间、互斥条件、动作先后、状态切换、故障或例外时，对照权项和实施例列出工况表。每行记录 **工况、输入或条件、触发前状态、动作或输出、后续状态、原文位置**。原文未说明的格写「未明示」，并注明可由图文确认、仅能推测或需研发确认。结合本案检查下列情形。

- **数值边界。** 单阈值分别检查低于、等于和高于。双阈值分别检查低端外侧、低端等值、两阈值之间、高端等值和高端外侧。核对单位、比较符、测量对象和测量位置。区间内动作可能依赖进入前状态时，分别核对两个进入方向和首次进入该工况时的状态。
- **启动与异常。** 在相关情况下检查上电、复位、超时、失效和恢复，核对首次动作、切换先后、保持或复位条件，以及条件同时触发时谁优先。对正常运行、部分堵塞和完全堵塞等工况分别核对触发原因、部件动作和结果。图中的静态位置可说明结构配合，动态动作和效果仍按各自证据核查。
- **路径与场景。** 从属项逐路径保留继承限定，核对新增条件在同一技术方案中能否成立。择一引用或项内替代结构分别列行，说明每一路的安装位置、接触对象和支持出处。只有文字记载的分支保留文字依据。正文条件与权项条件分开，避免把实施例的数值或例外并入权项。

发现缺口时，指出它影响哪个动作、分支或效果，列出待确认事实及条件成立后的候选改法。按「建议修改位置与改法」写清拟改位置，以及需要同步复查的图、权项或实施例。工程上的常见做法可以作为待验证解释，未确认前保留在报告或批注。

### 虚构示例

图 2（PDF 第 6 页）画出安装在种苗箱顶盖内侧的补光灯和安装在托盘旁的光照传感器。说明书 [0018] 记载「托盘旁的照度低于 40 lx 时开灯，高于 70 lx 时关灯」。权 1 只限定控制器根据照度控制补光灯。图可核对安装位置。阈值和控制动作按正文核查。

| 照度或工况 | 灯的动作或待核状态 |
| --- | --- |
| 低于 40 lx | 开灯，[0018]。 |
| 等于 40 lx | 未明示。 |
| 高于 40 lx 且低于 70 lx | 未明示，需分别确认此前开灯和此前关灯的情形。 |
| 等于 70 lx | 未明示。 |
| 高于 70 lx | 关灯，[0018]。 |
| 首次上电时照度为 40 至 70 lx | 初始灯态未明示。 |

**建议修改位置与改法**　核对两个等值点、区间内的实际灯态及上电默认状态。若确认进入闭区间后保持原状态，可在说明书 [0018] 的关灯语句之后插入「照度在 40 lx 至 70 lx（含端点）时，控制器维持补光灯进入该区间前的状态」。在同段初始化动作处按实际逻辑补写上电灯态，并同步复核时序图。阈值继续标作实施例信息，涉及权项取舍另行核对技术作用和影响。
