# 审稿与证据

## 审阅立场与法域

- 先区分申请人改稿、使用方评估第三方专利、给定文献比对和完整无效／FTO 工作。使用方报告中的候选改法用于理解范围变化及表达问题，不应写成已获授权代他人修改申请。
- 对外国案件，核实该法域官方规则与程序，再逐项判断。本文件涉及中国程序的条目只用于相应中国案件，不能平移成美国、欧洲等法域的结论。无法取得规则或案卷时保留缺口，继续做可核实的图文分析。
- 公开号、申请号、授权号分别写清。A1 等公开文本不自动等于现行审查文本或可执行权利。报告修订版与被审文件版本分列。
- 公开日期、主张优先权日和逐项有效申请日分开；写“早于／晚于”时带具体比较日期。引用同族及关联申请的权项时明确归属，不混成本案路径。

## 案件底稿

- 保留原件、文献号、稿件版本、阶段、语言和可复核位置。区分未取得、取得未核、核读后未见和明确披露。看图、核日期、读原文分别记录。
- 技术事实按使用情境、问题、部件位置或步骤、触发和动作、效果、替代方案整理。区别测试结果、交底主张和推断。发现矛盾时集中请研发确认。
- 为每个权项记录独立或从属、引用原句、所选路径、当前与继承的限定。保存“和／或”作用范围，不自动叠加兄弟分支。按同一组限定对应说明书、产品及对比文献。
- 记录技术事实、权利要求、说明书、附图、摘要、申请信息、独权新颖性与创造性的覆盖和未决。每条意见用稳定编号关联证据、法律判断、改法和处理状态。

## 原文与位置

- 每段原文与对应位置成对记录。PDF 页码从文件首页起算，印刷页码有用时另标。权利要求给出权项号、前序或特征部分及具体分句，说明书给出段号和句首锚词，摘要给出栏目和分句，附图给出图号和标号。跨页注明页码范围。
- 同一句在权项、摘要和说明书多次出现时，分别定位。合并显示相同摘录时保留全部位置。对照文件同时标明公开号、所用版本及核读位置。需要说明某项内容缺失时，摘录最接近的现有记载并交代查找范围。原件缺失或相关部分尚未核读时，标明未取得或未核读。
- 说明问题时，指出哪处文字未定义哪项关系、读者可能怎样理解，以及实际影响哪个权项、方案或工况。正文记载、图上可见、推断和研发待确认事项分别写明。

## 法律依据与判断

按法域、专利类型、案情阶段和适用时点核对现行及必要的历史规则。逐项确认来源文件全名、条款或节号、官方链接及对应事实。援引裁判时写明案号、裁判段落和可类比的解释方法，说明本案与该案的关键差别。未核到的依据标为待核。

| 意见类型 | 判断所需的证据 |
| --- | --- |
| 清楚性 | 哪个用语可能有不同含义，说明书、附图及本领域通常含义能否使技术人员合理确定其含义，以及不同理解会怎样影响保护范围。 |
| 说明书支持 | 哪项限定或概括缺少支持，以及原始说明书、附图和本领域知识能否支撑该范围。 |
| 充分公开 | 缺失的信息会否使本领域技术人员无法实施，或需要付出过度劳动。 |
| 新颖性与创造性 | 适用日期、可用的现有技术、特征对应及推理步骤。分别按独权检索要求记录。 |
| 撰写质量、保护层次或证据缺口 | 明确具体改进或补证用途。没有可核实法律依据时写明理由。 |

把法律定性与处理状态分开。证据足以支持具体判断时，写清依据和适用条件。证据仍待核验时，写出可能适用的依据与尚缺的判断环节。一般笔误、版面或保护层次优化按撰写问题记录。资料不足而无法判断时，说明要查哪份材料及哪一处。授权后是否可据此主张无效，需另查适用事由、证据和程序。

## 按阶段提出改法

| 审核阶段 | 候选改法的边界 |
| --- | --- |
| 申请前 | 从已核实的技术事实出发。可提出增加实施方式、图示或保护层次。尚待研发确认的内容保留在意见中。 |
| 审查中 | 核对原始申请文件、当前审查文本及审查意见。说明修改的原始依据、程序、期限和对保护范围的影响。 |
| 授权公告后 | 以授权文本为审核基准，分别说明解释口径和后续撰写建议。拟在无效程序中修改时，另核可用的权项修改方式、原始记载、范围和时机。按中国《专利法实施细则》第七十三条，在该程序中，发明和实用新型的权利要求修改不得扩大原保护范围，说明书和附图不得修改。见[国家知识产权局发布的实施细则](https://www.cnipa.gov.cn/art/2023/12/21/art_98_189197.html)。 |

## 独权检索和结论

每项独权先按当前文字进行宽检，再按关键结构关系、条件、同义术语、分类与已见区别补查。优先使用现有的智慧芽 MCP 权限，也可从公开检索和可核验的原文继续。用户仅给对比文献时标为给定文献比较。只有稿件时交付检索计划并标记未执行。向外部工具提交未公开内容时遵守已确认的数据使用范围。

记录检索式、来源、日期、过滤、命中及核读范围。对比文件先核对公开号、具体版本、公开日及适用日期。同族可用于发现文献，不替代被引用版本。单独记录可能的先申请后公开文献、事后线索和资格待核材料。按案件法域和阶段查现行官方规则。

未保存的原始命中数写“未记录”，没有执行完整分类检索就写明。报告里列出的核读文献数不能代替原始命中或完整筛选结果。首次出现 D1 等简称时同时给完整文献身份，文献目录说明核读到哪些段、项或图。初检只有组合线索时，不提升为完整无效结论；未核实单篇完整组合不等于确认新颖性。

- 新颖性按单篇文献中实际公开的一套技术方案逐项判断，包括特征间的配合、条件和选择。不可拼接不同文献或同篇文献中没有组合依据的方案。仅有摘要、未读附图或日期未核时，保留证据边界。
- 创造性记录起点、区别、效果、实际技术问题、启示或改进动机、结合条件与相反证据。区分已写入的限定、拟补表达和说明书解释。相似度只用于安排阅读。没有查到证据时写明本轮范围，保留未执行和未能取得的部分。
- 原稿与改写候选分别评价。增删或改变限定后，复查说明书依据、目标产品和从属路径，按变化补检。检索到预算或材料边界就列出剩余工作。

## 改法的落笔方式

每项改法单独写明目标位置、替换或插入等操作、候选文字、采纳条件和需要同步的位置。一条意见有多个落点时分项记录。

| 情形 | 改法内容 |
| --- | --- |
| 已确认的明确问题 | 原句、候选改后句、替换位置及需要同步修改的地方 |
| 保护层次有不同选择 | 对应权项及引用、各候选的依据、产品与检索影响 |
| 待补材料或待研发确认 | 具体缺什么、核验对象、条件成立后怎样补写。保留占位或条件，避免把待证内容写入清洁稿 |
| 已解决 | 可核验的原文与改后结果，标注已处理 |

改后复查说明书、权项、摘要、附图标记与引用的一致性。复核时根据原问题及其证据判断是否已解决。
